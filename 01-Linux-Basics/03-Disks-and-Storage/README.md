# Тема 1.3. Дисковая подсистема Linux: Inodes, разница df vs du, открытые удалённые файлы и I/O Wait
## 1. Тайна удалённого файла (Deleted but Open File)
В Linux удаление файла через `rm` удаляет только ссылку из каталога (dentry).  
Если процесс держит файл открытым, ядро **не освобождает дисковые блоки**, пока процесс не закроет файловый дескриптор.
### Как найти и расследовать:
```bash
# Поиск удалённых, но удерживаемых файлов:
lsof +L1 2>/dev/null
# или
lsof 2>/dev/null | grep deleted
Как освободить место БЕЗ перезапуска сервиса:
bash
# Очистить содержимое прямо через файловый дескриптор процесса в /proc:
> /proc/<PID>/fd/<FD_NUMBER>
# или
truncate -s 0 /proc/<PID>/fd/<FD_NUMBER>
2. Inodes (Иноды) и почему заканчивается место
Inode — структура данных файловой системы, хранящая метаданные о файле. Количество инодов задаётся при форматировании ФС.
Если иноды кончились (df -i показывает 100%), создание любого нового файла падает с ошибкой No space left on device, даже если на диске свободно 100 ГБ!
Типичная причина: миллионы мелких файлов кэша, PHP-сессий, временных файлов или очереди почты.
Поиск директорий с аномальным количеством файлов:
bash
find /var -xdev -printf '%h\n' | sort | uniq -c | sort -k 1 -nr | head -n 10
3. Разница между df и du
Команда	Что делает	Плюсы	Минусы
df (Disk Free)	Опрашивает суперблок файловой системы через системный вызов statfs().	Работает мгновенно (O(1)). Видит блоки, удерживаемые удаленными файлами.	Показывает только общую картину по точкам монтирования.
du (Disk Usage)	Рекурсивно обходит дерево директорий, вызывая stat() для каждого существующего файла.	Показывает точный размер каждой папки и файла.	Работает медленно при миллионах файлов. Не видит удалённые открытые файлы!
4. Диагностика узких мест диска (I/O Wait)

Высокий iowait в выводе top означает, что CPU простаивает в ожидании ответа диска.

bash
# Мониторинг утилизации дисков в реальном времени (каждую 1 секунду):
iostat -xz 1
%util: процент времени, когда диск был занят обработкой запросов (близко к 100% — диск перегружен).
await: среднее время ожидания I/O операции в миллисекундах (больше 10–20 мс — диск тормозит).
